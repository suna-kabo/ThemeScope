# Local delivery archives

Generated ZIPs are local, ignored outputs. This source tree no longer promises
prebuilt market-data bundles. Existing local archives are retained; older Git
commits may still contain them. They are not selected by Pages builds.

Use the current [Windows setup and CSV workflow](../README.md) to generate a
real selected session. Ordinary individual watchlists are rebuilt from unchanged
configuration; existing TradingView individual watchlists do not need reimporting.
Keep complete run bundles, inputs, audits and genuine history outside `site/`.
