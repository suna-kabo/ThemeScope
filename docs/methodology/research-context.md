# Research context

Current state, eligibility and priority rules follow [Research Logic v2](research-v2.md).
The original research-context contract remains for historical reads; Countertrend
no longer enters current snapshots or working screens.

SPY/QQQ Extension uses completed-session Wilder ATR20 and EMA21 distance. It is
context only. The unchanged Market Matrix owns market direction; IWM is context.

Competition ranks use valid Active Theme Scores with ties `1,2,2,4`. Filtering
does not rerank themes. Adjacent-session rank/EMA changes remain context, while
v2 compares exactly five sessions with explicit unavailable states when history,
methodology, series or calculation membership is incompatible.

Saved retains the original browser storage keys. A stored legacy lens does not
restore Countertrend; its ticker and theme context remain.
