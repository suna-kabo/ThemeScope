   validators; Gate A only with honest validation status and safe inspection output.
2. Phases 2–4: pure median/percentile/LOO engine, SQLite, agreed synthetic index,
   compatible history, daily liquidity and multi-theme exports; Gate B.
3. Phase 5: fixture and Alpaca SIP-only market-data adapters, mocked failure tests,
   local access PoC; Gate C. Live SIP success remains a local user check.
4. Phases 6–8: preserve Market Matrix; manual dated roster import; optional earnings;
   loopback FastAPI, atomic locked refresh and Windows launcher/UI; Gate D.
5. Phase 9: retire legacy default calculations only after A–D and cutover evidence
   requirements pass; preserve old history readers and keep main usable.
6. Phase 10: independent review passes, failure/replay/corporate-action fixtures,
   inspection secret/data scan; Gate E and PR to main. No self-merge/deployment.

No inspection checkpoint has passed or been pushed at Phase 0.
